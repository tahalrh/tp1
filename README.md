# Simple Projet HTML

Un projet web de démarrage simple, moderne et responsive.

## 📁 Structure des fichiers

- [index.html](index.html) : Structure HTML5 sémantique.
- [style.css](style.css) : Feuilles de styles CSS3 (Flexbox/Grid, mode sombre, design épuré).
- [script.js](script.js) : Interactions simples (compteur de clics et bascule thème clair/sombre avec mémorisation).

## 🚀 Comment l'ouvrir

1. Double-cliquez simplement sur le fichier `index.html` pour l'ouvrir dans votre navigateur web habituel (Chrome, Edge, Firefox, etc.).
2. Ou utilisez une extension comme *Live Server* dans VS Code pour un rechargement en direct lors des modifications.
